# AE2 Web Management — 模组

NeoForge 模组工程（Minecraft 1.21.1 / NeoForge 21.1.265）。游戏内数据出口，AE2 集成将在此实现。

> 权威文档见 [`docs/mod/index.md`](../docs/mod/index.md)；构建/环境说明见 [`docs/getting-started.md`](../docs/getting-started.md)。本文只作指针，请勿在此维护重复内容。

## 构建

在仓库根目录执行：

```powershell
.\mod\gradlew.bat -p .\mod build
```
